# Cardible Logo 使用规范（VI Guidelines）

> 本文档供**非设计同事**使用：照着选、照着下载、照着避坑即可，不需要懂设计。

---

## 1. 这个 logo 是什么样

Cardible 是**卡包 App**的品牌标识，主体为「**六边形抽象图标 + Cardible 字标**」。它和前面几个单色/渐变品牌不同，是**多色渐变全彩 logo**：

- **青绿**：`#70FEC2`
- **蓝**：`#5E67FF`
- **橙**：`#FF6E00`
- **琥珀 / 黄**：`#FFB500` / `#FED04B`
- **深紫**：`#34007F`
- **白**：`#FFFFFF`（图标内高光/细节）
- **字标金棕**：`#D5B17B`（"Cardible" 字样颜色，纯文字标也用此色）

我们提供三种版式：**横版组合**（图标 + 字标）、**图形标**（纯图标）、**纯文字标**（仅 Cardible 字样）。

⚠️ **最重要的一条**：Cardible 是**多色全彩** logo，**禁止改色、禁止压成单色/灰阶、禁止直接反白当深色版**。直接用我们提供的现成版本。

---

## 2. 该用哪一个？（选 logo 决策树）

你整理好的素材分两层：**标准交付**（横版组合）和**变体**（图形标、文字标）。

| 你的使用场景 | 用哪个文件 | 文件名 |
|---|---|---|
| **页眉 / 页脚 / 文档 / 网站导航** | 横版组合 | `标准交付/Cardible_logo.*` |
| **App 图标 / favicon / 头像 / 小方块** | 图形标（纯图标） | `变体/Cardible_图案_logo.*` |
| **仅需文字露出**：页脚署名、文档落款、与正文混排 | 纯文字标 | `变体/Cardible_文字_logo.*` |
| **浅色背景**（白/浅灰页面、文档） | 全彩版 | 以上文件（仅此一套） |
| **深色背景**（黑/深底、PPT 深色页） | ⚠️ 暂无 | 需从 `源文件/` 另出深色版，勿直接反白 |

**一句话**：横条排版用「标准交付」，小方块用「变体_图案」，只要字用「变体_文字」；目前只有浅色背景全彩版。

## 3. 文件格式怎么选

| 格式 | 给谁 | 什么时候用 |
|---|---|---|
| **SVG** | 开发 / 网页 / 任何需要放大的地方 | 首选，矢量无损，颜色永远清晰 |
| **PNG** | 所有人 | PPT、Word、微信/聊天、头像（透明底位图） |
| **PDF** | 印刷 / 物料打样 | 名片、海报、包装给印厂 |
| **AI**（在`源文件/`） | 仅设计师 | 需要改图、做深色版等特殊组合时 |

---

## 4. 留白（Clear Space）— 建议值

logo 四周必须保留空白，别让别的文字/图形贴着它。

- **建议留白**：≥ logo 自身高度的 **1/4**（上下左右都留）。
- 例：横版 logo 高 100px，四周至少留 25px 空白。
- *（此为通用安全值，若你们实际物料有更精确的规范可替换。）*

---

## 5. 最小尺寸（Minimum Size）— 建议值

太小会糊、细节看不清，不要用。

| 版本 | 屏幕（px）最小宽 | 印刷（mm）最小宽 |
|---|---|---|
| 横版组合 | 160px | 40mm |
| 图形标 | 48px | 12mm |
| 纯文字标 | 120px | 30mm |

- *（建议值，按实际物料微调。）*

---

## 6. 可以做 / 不可以做

✅ **可以**
- 用现成全彩版放在浅色/白色、对比度足够的干净背景上
- 按版面选横版组合、图形标或纯文字标
- 用 SVG / PNG / PDF 对应正确场景
- 等比缩放（锁定宽高比）

❌ **绝对禁止**
- 改颜色、压成单色/灰阶、把彩色当成纯色用
- 直接反白当成"深色版"用（深底需另出深色版）
- 拉伸 / 压扁 / 旋转 / 倾斜
- 加阴影 / 描边 / 底块 / 外发光等特效
- 把图形标和「Cardible」字标拆开重排

---

## 7. 源文件说明

`源文件/` 里是 Adobe Illustrator（.ai）原始稿，**仅供设计师修改使用**（包括制作深色背景版），普通同事不需要、也不要直接发 .ai 给外部。对外交付一律用 `标准交付/` 和 `变体/` 里的 SVG / PNG / PDF。

---

## 8. 快速自查清单

- [ ] 背景是浅还是深？→ 浅底用现成全彩版；深底需从源文件另出，勿反白
- [ ] 要横版组合 / 图形标 / 文字标？→ 选「标准交付 / 变体_图案 / 变体_文字」
- [ ] 格式对不对？→ 网页用 SVG，文档用 PNG，印刷用 PDF
- [ ] 四周留白够吗？→ ≥ 高度的 1/4
- [ ] 有没有改色 / 压单色 / 反白 / 拉伸 / 加特效？→ 有就改回
