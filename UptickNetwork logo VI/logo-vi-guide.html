二、选 logo 速决表

使用场景用哪个文件
浅色背景（白/浅灰页面、文档）「浅色背景」文件
深色背景（黑/深紫底、PPT 深色页）「深色背景」文件（白渐变）

三、文件格式怎么选

格式给谁什么时候用
SVG开发/网页首选，矢量无损，任意放大清晰
PNG所有人PPT、Word、微信/聊天、头像（透明底）
PDF印刷名片、海报、包装给印厂
AI（源文件/）仅设计师改图用，勿外发

四、品牌色（请勿改动）

主渐变-起 #6C06FC
主渐变-止 #B927ED
深紫文字/点缀 #2A005A
深底版白渐变 #FFFFFF → #F5CBF8

五、可以做 / 不可以做

✅ 可以做❌ 绝对禁止
• 按背景深浅选对版本
• 等比缩放（锁宽高比）
• 网页用 SVG / 文档用 PNG / 印刷用 PDF
• 放在对比度足够的干净背景上 		• 改颜色 / 压成单色 / 换其他紫
• 拉伸 / 压扁 / 旋转 / 倾斜
• 加阴影 / 描边 / 外发光 / 特效
• 把图形标和文字拆开重排
• 在花哨/低对比背景硬放
⚠️ 铁律：UptickNetwork logo 是紫罗兰渐变，禁止改色/压单色/拉伸。直接用现成版本，不要自己调。
