# UptickNetwork Logo 使用规范（VI Guidelines）

> 本文档供**非设计同事**使用：照着选、照着下载、照着避坑即可，不需要懂设计。

---

## 1. 这个 logo 是什么样

UptickNetwork 是**紫罗兰渐变字标**，不是单色、也不是纯文字。它的视觉特征：

- **主渐变**：`#6C06FC`（深紫罗兰）→ `#B927ED`（品红紫）
- **深紫文字/点缀**：`#2A005A`
- **深底版本**（用于黑色/深色背景）：白色 `#FFFFFF` → 浅粉 `#F5CBF8` 渐变

⚠️ **最重要的一条**：logo 本身是渐变，**禁止把它压成单色、禁止改色、禁止换其他紫**。直接用我们提供的现成版本。

---

## 2. 该用哪一个？（选 logo 决策树）

素材分两层：**标准交付**（横版）和**变体**（图案标 / 竖版）。每种版式都分「浅色背景」「深色背景」两版。

先看「背景深浅」，再看「摆放形状」。

| 版式 | 用在哪 | 浅色背景用 | 深色背景用 |
|---|---|---|---|
| **横版字标**（`标准交付/`） | 页眉 / 页脚 / 文档抬头 / 网页顶部 | `UptickNetwork_浅色背景.*` | `UptickNetwork_深色背景.*` |
| **图案标（方形标）**（`变体/`） | App 图标 / 头像 / 社交方形位 / favicon | `UptickNetwork_图案_浅色背景.*` | `UptickNetwork_图案_深色背景.*` |
| **竖版**（`变体/`） | 海报 / 启动页 / 易拉宝 / 竖屏广告 / 竖版物料 | `UptickNetwork_竖版_浅色背景.*` | `UptickNetwork_竖版_深色背景.*` |

**一句话**：先看**背景**（浅底用「浅色背景」文件、深底用「深色背景」文件），再看**版式**（横条 / 方形 / 竖版）。

---

## 3. 文件格式怎么选

| 格式 | 给谁 | 什么时候用 |
|---|---|---|
| **SVG** | 开发 / 网页 / 任何需要放大的地方 | 首选，矢量无损，颜色永远清晰 |
| **PNG** | 所有人 | PPT、Word、微信/聊天、头像（透明底位图） |
| **PDF** | 印刷 / 物料打样 | 名片、海报、包装印刷给印厂 |
| **AI**（在`源文件/`） | 仅设计师 | 需要改图、做特殊组合时，不要发给普通同事 |

---

## 4. 留白（Clear Space）— 建议值

logo 四周必须保留空白，别让别的文字/图形贴着它。

- **建议留白**：≥ logo 自身高度的 **1/4**（上下左右都留）。
- 例：横版 logo 高 100px，四周至少留 25px 空白。
- *（此为通用安全值，若你们实际物料有更精确的规范可替换。）*

---

## 5. 最小尺寸（Minimum Size）— 建议值

太小会糊、字看不清，不要用。

| 版本 | 屏幕（px）最小宽 | 印刷（mm）最小宽 |
|---|---|---|
| 横版字标 | 120px | 30mm |
| 图案标（方形标） | 48px | 12mm |

- *（建议值，按实际物料微调。）*

---

## 6. 可以做 / 不可以做

✅ **可以**
- 按背景深浅选对版本（浅底→浅色背景文件，深底→深色背景文件）
- 等比缩放（锁定宽高比，不放变形）
- 用 SVG / PNG / PDF 对应场景
- 放在有足够对比度的干净背景上

❌ **绝对禁止**
- 改颜色、把渐变压成单色、换其他紫色
- 拉伸 / 压扁 / 旋转 / 倾斜
- 加阴影、描边、外发光、其他特效
- 把图案标和文字拆开重新排列
- 在花哨 / 低对比度背景上硬放（换对应深浅版本或加底块）

## 8. 快速自查清单

- [ ] 背景是浅还是深？→ 选对「浅色背景 / 深色背景」文件
- [ ] 要横条、方形还是竖版？→ 选「标准交付 / 图案 / 竖版」
- [ ] 格式对不对？→ 网页用 SVG，文档用 PNG，印刷用 PDF
- [ ] 四周留白够吗？→ ≥ 高度的 1/4
- [ ] 有没有改色 / 拉伸 / 加特效？→ 有就改回
