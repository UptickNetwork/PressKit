# Vouch Logo 使用规范（VI Guidelines）

> 本文档供**非设计同事**使用：照着选、照着下载、照着避坑即可，不需要懂设计。

---

## 1. 这个 logo 是什么样

Vouch 是 **DID + VC 证书产品**的品牌标识，主体为「**六边形徽标 + Vouch 字标**」。它的配色逻辑和前面几个渐变品牌不同：

- **唯一品牌色（紫色点缀）**：`#CD65F3`
- **浅色背景版**：主标记（六边形 + Vouch 字标）为**黑色** `#000000`，内衬白、紫交点缀
- **深色背景版**：主标记为**白色** `#FFFFFF`，紫色 `#CD65F3` 点缀

⚠️ **最重要的一条**：Vouch 不是渐变 logo，而是「单色主标记 + 紫色点缀」。**禁止改色、禁止把紫色 `#CD65F3` 换成别的颜色、禁止压成纯灰阶/单色**。直接用我们提供的现成版本。

---

## 2. 该用哪一个？（选 logo 决策树）

你整理好的素材分两层：**标准交付**（横版）和**变体**（图形标 / 竖版）。先看「摆放形状」，再看「背景深浅」。

| 你的使用场景 | 用哪个文件 | 文件名 |
|---|---|---|
| **页眉 / 页脚 / 文档 / 网站导航** | 横版组合 | `标准交付/Vouch_浅色背景` 或 `Vouch_深色背景` |
| **App 图标 / favicon / 头像 / 小方块** | 图形标（纯徽标） | `变体/Vouch_图案_浅色背景` 或 `Vouch_图案_深色背景` |
| **社交方形位 / App 启动页 / 上下叠的方块** | 竖版 | `变体/Vouch_竖版_浅色背景` 或 `Vouch_竖版_深色背景` |
| **浅色背景**（白/浅灰页面、文档） | 黑标版 | 文件名含「浅色背景」 |
| **深色背景**（黑/深紫底、PPT 深色页） | 白标版 | 文件名含「深色背景」 |

**一句话**：横条排版用「标准交付」，纯图标用「变体_图案」，上下叠用「变体_竖版」；浅底用「浅色背景」，深底用「深色背景」。

## 3. 文件格式怎么选

| 格式 | 给谁 | 什么时候用 |
|---|---|---|
| **SVG** | 开发 / 网页 / 任何需要放大的地方 | 首选，矢量无损，颜色永远清晰 |
| **PNG** | 所有人 | PPT、Word、微信/聊天、头像（透明底位图） |
| **PDF** | 印刷 / 物料打样 | 名片、海报、包装给印厂 |
| **AI**（在`源文件/`） | 仅设计师 | 需要改图、做特殊组合时，不要发给普通同事 |

---

## 4. 留白（Clear Space）— 建议值

logo 四周必须保留空白，别让别的文字/图形贴着它。

- **建议留白**：≥ logo 自身高度的 **1/4**（上下左右都留）。
- 例：横版 logo 高 100px，四周至少留 25px 空白。
- *（此为通用安全值，若你们实际物料有更精确的规范可替换。）*

---

## 5. 最小尺寸（Minimum Size）— 建议值

太小会糊、字看不清，不要用。

| 版本 | 屏幕（px）最小宽 | 印刷（mm）最小宽 |
|---|---|---|
| 横版组合 | 160px | 40mm |
| 图形标（变体_图案） | 48px | 12mm |
| 竖版 | 96px | 24mm |

- *（建议值，按实际物料微调。）*

---

## 6. 可以做 / 不可以做

✅ **可以**
- 按背景深浅选对版本（浅底→浅色背景文件，深底→深色背景文件）
- 等比缩放（锁定宽高比，不放变形）
- 用 SVG / PNG / PDF 对应正确场景
- 放在对比度足够、不花哨的干净背景上

❌ **绝对禁止**
- 改颜色、把紫色 `#CD65F3` 换成别的颜色、压成纯灰阶/单色
- 拉伸 / 压扁 / 旋转 / 倾斜
- 加阴影 / 描边 / 外发光 / 其他特效
- 把图形标和「Vouch」文字拆开重排
- 在复杂、低对比背景上硬放（应换对应深浅版本或加底块）

`源文件/` 里是 Adobe Illustrator（.ai）原始稿，**仅供设计师修改使用**，普通同事不需要、也不要直接发 .ai 给外部。对外交付一律用 `标准交付/` 和 `变体/` 里的 SVG / PNG / PDF。

## 8. 快速自查清单

- [ ] 背景是浅还是深？→ 选对「浅色背景 / 深色背景」文件
- [ ] 要横版、纯图形标、还是竖版？→ 选「标准交付 / 变体_图案 / 变体_竖版」
- [ ] 格式对不对？→ 网页用 SVG，文档用 PNG，印刷用 PDF
- [ ] 四周留白够吗？→ ≥ 高度的 1/4
- [ ] 有没有改色 / 拉伸 / 加特效？→ 有就改回
