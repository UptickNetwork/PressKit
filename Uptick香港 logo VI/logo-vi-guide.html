三、选 logo 速决表

使用场景用哪个文件
浅色背景（白/浅灰页面、文档）文件名含「浅色背景」
深色背景（黑/深紫底、PPT 深色页）文件名含「深色背景」（反白渐变）

四、文件格式怎么选

格式给谁什么时候用
SVG开发/网页首选，矢量无损，任意放大清晰
PNG所有人PPT、Word、微信/聊天、头像（透明底）
PDF印刷名片、海报、包装给印厂
AI（源文件/）仅设计师改图用，勿外发

五、品牌色（请勿改动）

主渐变-起 #FF74E4
主渐变-止 #F032B4
浅底版文字/底块 #000000
深底版反白渐变 #FFFFFF → #F5C0F0

六、可以做 / 不可以做

✅ 可以做❌ 绝对禁止
• 按背景深浅选对版本
• 等比缩放（锁宽高比）
• 网页用 SVG / 文档用 PNG / 印刷用 PDF
• 放在对比度足够的干净背景上 		• 改颜色 / 压成单色 / 换成紫色
• 拉伸 / 压扁 / 旋转 / 倾斜
• 加阴影 / 描边 / 外发光 / 特效
• 把图形标和「UPTICK」文字拆开重排
• 在花哨/低对比背景硬放
⚠️ 铁律：Uptick香港 图形标是粉红渐变（#FF74E4 → #F032B4），禁止改色/压单色/拉伸。直接用现成版本，不要自己调。
