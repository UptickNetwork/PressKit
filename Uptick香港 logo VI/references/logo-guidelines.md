# Uptick香港 Logo 使用规范（VI Guidelines）

> 本文档供**非设计同事**使用：照着选、照着下载、照着避坑即可，不需要懂设计。

---

## 1. 这个 logo 是什么样

Uptick香港是 **Uptick 品牌香港场景的本地化版本**，标识主体为「**UPTICK 字标 + 图形标**」。

- **主渐变（图形标）**：`#FF74E4`（亮粉）→ `#F032B4`（品红）
- **浅底版文字/图形标底块**：黑色 `#000000`
- **深底版全部元素**：白→浅粉渐变 `#FFFFFF → #F5C0F0`（近似 `#F5CBF8`）

⚠️ **最重要的一条**：图形标是粉红渐变，**禁止把它压成单色、禁止改色、禁止换成紫色（Uptick 主品牌紫）**。直接用我们提供的现成版本。

---

## 2. 该用哪一个？（选 logo 决策树）

你整理好的素材分三层：**标准交付**（横版）和两种**方形变体**。先看「摆放形状」，再看「背景深浅」。

| 你的使用场景 | 用哪个文件 | 文件名 |
|---|---|---|
| **页眉 / 页脚 / 文档 / 网站导航** | 横版字标 | `标准交付/Uptick香港_浅色背景` 或 `Uptick香港_深色背景` |
| **App 图标 / favicon / 头像 / 小方块** | 方形图形标 | `变体/Uptick香港_01浅色背景` 或 `Uptick香港_01深色背景` |
| **社交方形位 / App 启动页 / 需要 mark+字上下叠的方块** | 方形上下组合 | `变体/Uptick香港_02浅色背景` 或 `Uptick香港_02深色背景` |
| **浅色背景**（白/浅灰页面、文档） | 彩色渐变版 | 文件名含「浅色背景」 |
| **深色背景**（黑/深紫底、PPT 深色页） | 白渐变反白版 | 文件名含「深色背景」 |

**一句话**：横条排版用「标准交付」，小方块用「变体_01（纯图形标）」或「变体_02（上下组合）」；浅底用「浅色背景」，深底用「深色背景」。

---

## 3. 文件格式怎么选

| 格式 | 给谁 | 什么时候用 |
|---|---|---|
| **SVG** | 开发 / 网页 / 任何需要放大的地方 | 首选，矢量无损，颜色永远清晰 |
| **PNG** | 所有人 | PPT、Word、微信/聊天、头像（透明底位图） |
| **PDF** | 印刷 / 物料打样 | 名片、海报、包装给印厂 |
| **AI**（在`源文件/`） | 仅设计师 | 需要改图、做特殊组合时，不要发给普通同事 |

---

## 4. 留白（Clear Space）— 建议值

logo 四周必须保留空白，别让别的文字/图形贴着它。

- **建议留白**：≥ logo 自身高度的 **1/4**（上下左右都留）。
- 例：横版 logo 高 100px，四周至少留 25px 空白。
- *（此为通用安全值，若你们实际物料有更精确的规范可替换。）*

---

## 5. 最小尺寸（Minimum Size）— 建议值

太小会糊、字看不清，不要用。

| 版本 | 屏幕（px）最小宽 | 印刷（mm）最小宽 |
|---|---|---|
| 横版字标 | 120px | 30mm |
| 方形图形标（变体_01） | 48px | 12mm |
| 方形上下组合（变体_02） | 64px | 16mm |

- *（建议值，按实际物料微调。）*

---

## 6. 可以做 / 不可以做

✅ **可以**
- 按背景深浅选对版本（浅底→浅色背景文件，深底→深色背景文件）
- 等比缩放（锁定宽高比，不放变形）
- 用 SVG / PNG / PDF 对应正确场景
- 放在对比度足够、不花哨的干净背景上

❌ **绝对禁止**
- 改颜色、把渐变压成单色、换成 Uptick 主品牌紫色
- 拉伸 / 压扁 / 旋转 / 倾斜
- 加阴影 / 描边 / 外发光 / 其他特效
- 把图形标和「UPTICK」文字拆开重排
- 在复杂、低对比背景上硬放（应换对应深浅版本或加底块）

## 8. 快速自查清单

- [ ] 背景是浅还是深？→ 选对「浅色背景 / 深色背景」文件
- [ ] 要横条、纯图形标、还是上下组合？→ 选「标准交付 / 变体_01 / 变体_02」
- [ ] 格式对不对？→ 网页用 SVG，文档用 PNG，印刷用 PDF
- [ ] 四周留白够吗？→ ≥ 高度的 1/4
- [ ] 有没有改色 / 拉伸 / 加特效？→ 有就改回
